# Third-party assets

Production frontend dependencies retain their existing licenses. This package copies the frontend build without modifying its bundled code.

Local font files are cached from the same Google Fonts stylesheet used by production: DM Mono, Inter and Noto Sans SC. These font families are distributed under the SIL Open Font License 1.1. Font data is not modified.

- DM Mono: https://github.com/googlefonts/dm-mono
- Inter: https://github.com/rsms/inter
- Noto Sans SC: https://github.com/notofonts/noto-cjk
- SIL Open Font License: https://openfontlicense.org/open-font-license-official-text/

Existing digital-human images and video clips are copied from this project's production `frontend/dist/media` directory. Their original usage restrictions remain applicable. They are not newly generated for this recording.
