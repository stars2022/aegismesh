# 前端审计报告（2026-10-12）

范围：`frontend/` 全部源码，包括聊天工作台、手机端抽屉、登录页、管理后台 10 个页面、设置弹窗。

方法：
- 运行 `tsc`、生产构建和全部单元测试。
- 在 demmo.cc.cd 以访客身份只读走查。
- 用项目自带的隔离预览页（`tests/*.html`，端口 5197）走查管理后台各页，覆盖 1440 / 1200 / 375 三种宽度和深色模式。
- 用脚本逐页统计字号、圆角、对比度、截断和无名控件。

线上资源的哈希值（如 `index-BvrG3JdJ.js`）与本地构建一致，说明线上版本就是当前源码。

## 总体结论

工程基础是健康的：
- 类型检查 0 错误；111 个单元测试全部通过。
- 线上控制台无报错，没有用到 `dangerouslySetInnerHTML`，没有遗留 `console.log`。
- 所有 `target="_blank"` 都带了 `rel="noopener noreferrer"`。

问题集中在三处：
- 视觉规格失控：33 种字号、18 种圆角、20 个断点。
- 少数会导致白屏或布局溢出的真实缺陷。
- 样式层层打补丁，导致改一处牵动多处。

## P1 · 视觉一致性（"不协调"感的来源）

### 规格数值失控（CSS 实际统计）

| 维度 | 现状 | 建议 |
|---|---|---|
| 字号 | **33 种**，含 6 / 8 / 8.5 / 9 / 9.5 / 10.5 / 11.5 / 12.5 / 13.5px；小于 11px 的声明有 **99 处** | 收敛为 11 / 12 / 13 / 15 / 18 / 24 六级 |
| 圆角 | **18 种**（2–22px 几乎每个整数都有）；聊天页一屏就同时出现 13 种 | 收敛为 6 / 8 / 12 / 999 四级 |
| 断点 | **20 个**（820px、44rem、650、600、570、560、540、480…） | 收敛为 3 个：手机、平板、桌面 |
| z-index | **33 种取值**，0 到 1200 | 定义一组层级变量 |
| `!important` | **187 处** | 合并规则后逐步去掉 |

- 6236 行："微信式统一入口列表"
- 7442 行："深色模式彻底覆盖"
- 8600 行："Final navigation surfaces"
- 10279 行：统一折叠按钮

`.route-inspector` 在 12 处以上被重新定义，`.history-sidebar` 在 10 处以上。这就是改了一处、另一处被覆盖回去，以及数值越来越杂的根源。

### 具体不协调点

- **侧边栏标题**：分组标题"今天 / 更早"只有 **8px**，对比度 2.76:1（[styles.css:736](../frontend/src/styles.css)）。管理后台的"工作区"标签是 11px，对比度 2.79:1。两套侧边栏的同类标题用了不同规格。
- **侧边栏按钮**：新会话按钮高 40px、12px 字、圆角 12；历史条目高 36px、圆角 7（外框 12，内外弧度不一致）；API 入口圆角 7；账号行高 52px、圆角 10；折叠按钮 34px、圆角 10 且带边框，和周围无边框的条目不是一个风格。各元素左边起点分别在 18、22、20、21px，没有对齐。
- **黑色主按钮太多**：智能体管理页一屏有 3 个纯黑按钮（新建智能体、打开聊天、创建智能体）；日志页的"查询"按钮单独占一行，也是黑色。主次层级不清楚。
- **禁用态太重**：登录和保存按钮在禁用时是一整块深灰实心，看起来像出错，而不是"还不能点"。
- **两个登录页是两套设计**：用户登录 `/login` 是左对齐的整页表单，三个按钮（登录、注册、忘记密码）等权重排成一排；管理员登录 `/admin` 是居中卡片带阴影，标签只有 **10px**（[styles.css:404](../frontend/src/styles.css)）。
- **空状态文字**：统一是 10px 字，对比度 **2.73:1**（[styles.css:451](../frontend/src/styles.css)），探针页、运行记录页、供应商页都用到。
- **输入框**：桌面端输入文字只有 **11px**（[styles.css:1207](../frontend/src/styles.css)），比正文还小；背景是偏冷的灰色，加上发送按钮的禁用灰，整体看起来像被禁用。
- **右侧统计卡**：1200px 宽时"输入 Token / 输出 Token"会折成两行。
- **强调色写死**：靛蓝 `#4f46e5 / #6366f1` 直接写在约 50 处，包括 CSS 和 TSX 行内样式。styles.css 的令牌块之外还有 221 个写死的颜色值，TSX 里有 117 处 `style={{…}}`。以后换主题或调色会很难。
- **原生弹窗**：有 10 处用了 `alert` / `confirm`（例如 App.tsx:993、3090、8603），而设置弹窗里已经有自绘的确认 UI，两种风格混用。

## P2 · 可访问性

- 低对比度普遍存在。`--c999993`、`--c9a9a94` 这类弱化文字在浅色底上大约只有 2.7–2.9:1，用在分组标题、空状态、耗时、副标题上。分段标签的未选中态是 3.58:1，输入框下方的"上传材料"和智能体选择器是 3.69:1。WCAG AA 要求 4.5:1。
- 聊天输入框没有可读的标签，只有 placeholder。运行记录页的搜索框也一样。
- 智能体管理页的"全网发现池"开关没有可访问名称（App.tsx:1110）。文字放在旁边一个独立按钮里，没有用 `Switch` 的 `label` 参数。
- 有 25 处 `outline: 0/none`。登录输入框的焦点样式是 6% 透明度的阴影（[styles.css:406](../frontend/src/styles.css)），用键盘操作时几乎看不出当前焦点在哪。

## P3 · 工程与性能

- **巨型文件**：`App.tsx` 有 10,070 行，159 个 `useState`，30 多个组件（管理后台 10 个页面加整个聊天工作台）都在一个文件里；`styles.css` 有 10,702 行。
- **`npm run lint` 跑不起来**：package.json 声明了这个脚本，但没装 eslint，也没有配置文件。
- **依赖版本不固定**：8 个依赖写的是 `"latest"`（react、vite、typescript 等），当前解析到了 vite 8.3。每次重新安装都可能拿到新的大版本。
- **体积**：
  - `CanvasWorkspace` 包 536KB（gzip 后 168KB），构建时有超限警告。
  - `SettingsDialog` 包 176KB，对一个设置弹窗来说偏大，值得查一下引入了什么。
  - 主 CSS 248KB 首屏全量加载，里面包含了管理后台的样式。
- **字体**：通过 CSS `@import` 引入 Google Fonts（[styles.css:1](../frontend/src/styles.css)），这是串行阻塞加载。改成 `index.html` 里用 `<link rel="preconnect">` 加 `<link>` 会更快。
- **仓库里有旧构建产物**：`frontend/dist-*` 有 7 个历史构建目录被提交进了 git（`frontend/dist/` 本身已被忽略）。

## 建议的修复顺序

1. **半天**：P0 的 1–8 条，都是局部改动。加错误边界、改 grid 列宽、去掉抽屉上边距、保存设置加 try/catch、补空状态、改按自然日分组、修截断。
2. **1–2 天**：定义一套设计令牌（字号 6 级、圆角 4 级、间距、层级、强调色变量），先套在侧边栏、按钮、登录页、空状态这几处"不协调"最明显的地方。
3. **持续进行**：把 styles.css 按区域拆分，合并重复规则，逐步去掉 `!important`；把 App.tsx 的管理后台页面拆成独立文件；修好 lint，固定依赖版本；清理 `dist-*`。

## 处理结果（同日）

### 已修复

- **P0**
  - 新增错误边界 `ErrorBoundary`：根节点整页兜底；管理后台按页面单独兜底，某一页出错时侧栏导航仍然可用。
  - 手机端账号管理不再横向溢出。除了 grid 列宽问题，还有一个原因：表头里视觉隐藏的绝对定位元素跑出了滚动容器。
  - 路由抽屉去掉多余的一层顶部。
  - 手机端空白会话页不再出现滚动。原因是首页卡片区和对话区重复预留了输入框的高度。
  - 智能体管理页补上空状态。
  - 保存设置加了容错。
  - 历史记录改为按本地自然日分组，并新增"昨天"分组。
  - 修复"登录账号"和品牌名被截断的问题。
- **侧边栏**：聊天和管理后台两套侧栏统一使用 `--sidebar-*` 令牌（行高 36、圆角 8、字号 13 / 11），左缘全部对齐。主按钮改为浅色描边。侧栏展开时，折叠按钮改为无边框。
- **字号**：styles.css 中所有小于 11px 的字号都已提到 11 或 12px。正文类的空状态和登录标签是 12px，聊天输入框是 14px。
- **对比度**：
  - 浅色主题里用作文字的 27 个弱灰令牌统一改为 `#6c6c66`，对比度约 5:1。
  - `--muted` 加深一档。
  - 状态徽章改用语义色令牌。
  - 深色主题的强调色改浅。
  - 修正了深色卡片上的标签颜色。
- **强调色**：约 50 处写死的靛蓝改为 `--accent` 系列变量。补上了缺失的 `--accent-soft`，另外有 7 个"用了但没定义"的变量改为引用已有令牌。
- **按钮**：主按钮和发送按钮的禁用态改为浅灰底；顶栏"打开聊天"改为次级样式。用户登录页和管理员登录页统一为居中卡片，"忘记密码"降级为文字链接。
- **输入区**：输入框改为白底描边。空会话不显示上下文圆环。第四张推荐卡片换了专属图标。
- **可访问性**：聊天输入框、运行记录搜索框、全网发现池开关补上可访问名称；登录输入框的焦点样式加强；标签页文字不可选中。
- **工程**：
  - Google Fonts 改为在 `index.html` 里预连接加载。
  - 8 个 `latest` 依赖固定为当前安装的版本。
  - 删掉跑不起来的 `lint` 脚本，新增 `typecheck` 和 `test` 脚本。
  - 7 个旧构建目录 `dist-*` 不再纳入版本管理（本地文件保留）。

### 第二轮（遗留项）

- **拆分 `App.tsx`**：
  - 管理后台的 8 个页面移到 `src/admin/`，聊天相关移到 `src/chat/`，`App.tsx` 只剩约 270 行的后台外壳。
  - 聊天页不再加载后台代码：原来两者共用一个 293KB 的包，现在聊天 142KB、后台 137KB。
  - 设置弹窗的包从 176KB 降到 18KB。
- **拆分 `styles.css`**：按区域拆成 `src/styles/` 下 18 个文件，由入口按原顺序引入。拆分前后构建出的 CSS 逐字节一致。
- **断点**：540、560、570、650px 并入 600px，统一为 360 / 480 / 600 / 820 / 1050 五档。数字人页的 rem 断点和容器查询属于组件内部规则，保留不变。
- **层级**：18 个全局 z-index 改为 `--z-*` 命名变量，数值和相对关系不变。
- **`!important`**：用计算样式比对验证（18 个预览页 × 浅色/深色 × 桌面/手机，共 72 组，两次空跑 0 差异）。
  - 去掉了 18 处去掉后样式完全不变的。
  - 另有 8 处去掉后会产生差异，已恢复。
  - 剩余 166 处里，多数针对预览页没有渲染出来的界面（群聊抽屉、黑板、画布等）或悬停/焦点状态，无法验证，所以保留。
- **原生弹窗**：11 处 `alert` / `confirm` 换成应用内对话框（`src/dialog.tsx`）。支持 Esc 关闭、焦点循环；危险操作默认聚焦"取消"。
- **体积**：
  - 第三方库拆成 `vendor-react`、`vendor-markdown`、`vendor-editor` 三个长期缓存包。
  - 画布编辑器包（506KB，几乎全是 tiptap / prosemirror）只在打开画布时懒加载，属于编辑器本身的体积，无法靠删代码缩小。
- **数字人页**：
  - 改为一屏布局：整页固定为屏幕高度，三栏底边对齐，只有对话记录在内部滚动。
  - 在 1920×1080 到 375×667 共 9 种尺寸下验证，均无整页滚动。
  - 矮屏手机上隐藏底部说明条和声音设置，把空间让给对话区。
- **协作面板**："主智能体工具记录"的标题改为与"本会话协作"同一层级的样式，不再是浏览器默认的 ▶ 大字。
