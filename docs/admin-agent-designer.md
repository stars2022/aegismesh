# 管理面板 AI 创建智能体

## 使用与边界

侧栏和智能体管理页复用同一分体按钮。点击“新建智能体”主体直接打开原手动创建表单；只有点击箭头并选择“AI 生成”，才进入 AI 创建界面。不会记住 AI 模式或把主按钮改成生成。

桌面侧栏缩成图标栏时，仅保留一个“＋”菜单按钮，展开后选择手动创建或 AI 生成，不在窄按钮内继续分栏。窄屏使用完整导航抽屉，按钮关闭的是抽屉，不修改桌面折叠状态；调整视口后也不会把图标栏样式套进抽屉。界面不显示额度豁免说明。

AI 界面输入需求并选择现有模型供应商，生成后进入“预览 AI 草稿”的原创建表单，名称、技能、工具、提示词、模型及可选结构化能力都可编辑。只有最终点击“保存智能体”才通过现有创建接口保存为本地内部智能体；不会自动注册 AIC、签发证书、提审或上线。

这不是一个存储在 `agents` 表中的业务智能体，不加入聊天选择器、路由目录、协作工具或 AIP/MQ 注册。管理员专用 `POST /api/admin/agent-designer/generate` 强制使用现有 `require_admin`，公开 API Key、访客或普通账号不能调用；独立 AIP 监听进程即使收到管理员请求也拒绝提供该功能。客户端不能通过参数声明管理员身份或额度豁免。生成出来的业务智能体仍按原有用户/角色规则计量，不继承创建功能的豁免。

## 额度豁免与费用

仅该鉴权后端路径使用专用 `admin_designer_scope`：不申请普通任务轮次，不受账号、角色、公开共享及供应商应用额度拦截；不修改全站策略、其他角色或 service 豁免。内部专用主体为 `admin-designer:<管理员>`，`ModelUsage.exempt=true`，实际 Token 及失败时的估算仍入账，额度模块关闭时也保留这类计量。

豁免不是免费服务，也不绕过上游限速、余额或权限。每次明确提交仅发起一轮无工具、无自动重试的模型生成，单次输出最多 4096 Token、最多 90 秒；同管理员已有请求时拒绝重复点击。这些是单请求资源边界，不是普通用户额度。上下文在成功、异常和取消后都恢复，不能由智能体名称、普通聊天参数或嵌套请求继承。

关闭生成界面会停止浏览器等待，不保证已发出的上游生成立即取消或退款；服务端仍受上述超时边界约束，并保留已发生用量。

每次付费调用前先落审计预留；不可落审计则不发调用。审计记操作者、供应商、模型、结果及用量，不记需求文本、生成提示词、完整草稿或密钥。格式错误、越界工具、权限字段、无效 Schema 均拒绝，不会自动补调。

## 实现和验证

- `backend/app/agent_designer_api.py`：独立管理员路由；只返回经过校验的配置。模型不能选择密钥、端点、AIC、供应商或额度；供应商由管理员的明确选择固定。与现有 ID 冲突时返回新的草稿 ID，不覆盖原记录。
- `frontend/src/admin/NewAgentMenu.tsx`：共享分体菜单，支持外点关闭、Escape、方向键以及移出侧栏裁切区的菜单浮层。
- `frontend/src/admin/AgentDesigner.tsx`：生成表单与取消；复用 `AgentBuilder` 预览和确认，普通手动入口不调用模型。
- `backend/tests/test_agent_designer.py` 和 `frontend/tests/adminDesignerApi.test.mjs` 验证鉴权、豁免隔离、真实 HTTP 请求形状、无工具/递归、错误结果不落业务记录、审计与无自动重试。
- `frontend/tests/agent-designer.html` 为完全隔离的 UI 预览，仅样例数据，不使用生产密钥或连接线上服务；可加 `?integration=1&tab=studio&viewport=responsive` 在真实 iframe 内切换 390、760、820、821、1024px 视口，保留应用状态，检查折叠栏与导航抽屉之间的切换。

本轮不部署服务器，不修改线上配置，也不以模拟生成冒充真实供应商验收。上线后应使用管理员选定的供应商进行一次有审计的真实验证。
