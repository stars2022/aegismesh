# 会话同步与恢复

工作台历史以服务端校验的 browser owner 为边界，不以邮箱、IP、前端 userId 或 owner/admin 角色越权合并。

- `/api/account/history` 分页返回本人会话，包括已有任务但尚无浏览器快照的旧会话；不再截断为 50 条。
- `GET /{session}` 恢复消息，按所属调用记录补齐已完成或失败的任务，并恢复路由结果。读取不会重新执行任务。
- `PUT /{session}` 保存消息、附件元数据、会话类型和配置。云端只存调用引用，读取时从本人任务恢复结果，避免重复保存大段工具回执。
- 每次保存携带 revision，数据库条件更新防止跨页面覆盖；冲突读取新版本并保留双方消息，只重试一次。离线失败保留本地副本，重新聚焦、联网或手动同步时重试。
- 流式 token 不写云端；终态消息防抖保存。未完成任务仍由已有任务恢复接口处理，不因读取会话重新计费。
- 删除是带 revision 的软删除，陈旧页面不能重新上传复活；设置 → 数据管理可恢复。不删除 Invocation 或审计证据。
- 请求携带预期 owner，账号切换后拒绝旧页面的延迟写入。服务端仍以 cookie 验证的身份授权，不能通过该请求头选择别人的身份。
- 访客继续使用隔离的本地历史，不开放匿名云端写入；账号云端历史跟随已验证的登录身份，模块关闭不影响公开 demo 或已有有效身份的记录读取。

## 旧缓存

旧无命名空间的 `aegismesh-conv-*` 不会自动认领。设置 → 数据管理提供明确确认的导入：复制为新会话，移除旧调用、群聊、任务句柄，保留原始缓存，不转移旧任务所有权。排队任务不会从另一浏览器自动执行。当前账号自己的旧服务端会话会自动恢复，无需导入。

浏览器缓存清理与云端删除分开。缓存清除后已同步的会话仍可从云端恢复，未同步草稿须先保存。云端单次保存上限 2 MiB、2000 条消息，账号快照上限 2000 个/64 MiB；服务器剩余空间低于 512 MiB 时停止新快照写入。超过上限会提示并保留本地内容，不截断。软删除快照仍占容量，以保留可恢复性。

## 验证与部署

`backend/tests/test_conversation_history.py` 验证隔离、旧会话恢复、分页、并发写保护、软删除/恢复、CSRF、大小限制及模块关闭。
`frontend/tests/conversationSync.test.mjs` 验证合并、旧缓存显式导入、离线保存和恢复。
`frontend/tests/conversation-sync.html` 为隔离 UI 样例，所有请求拦截，不调用真实模型。

生产部署前使用 `scripts/backup-production.py --stream-database` 将一致性 SQL 备份直接回传本机，配置归档单独备份；`scripts/verify-history-backup.py` 在本地恢复并校验，禁止在生产磁盘恢复大备份。`scripts/deploy-history-sync.py` 验证文件白名单、备份与活跃任务，增建历史表，仅重启 API，保留账号、配额、供应商、身份和审计配置，失败恢复代码及前端入口。
