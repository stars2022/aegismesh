# AegisMesh 原版界面离线演示

不是重做的原型：`dist/assets`、`dist/media` 来自正式前端同一套源码构建 `cf85ef7`，manifest 列出的 32 个资源与该构建逐字节一致。此版包含深色代码块、群聊黑板及普通聊天输入框修复，未因此部署或重启云端服务。仅 HTML 入口先安装预置接口层，再加载共享前端。原版字体也缓存在本地。

## 启动

双击 `启动演示.command`，或在此目录运行 `python3 serve.py`。只需 Python 3，无需 npm、数据库、模型密钥或正式账号。Ctrl+C 停止服务。

- 主页：<http://127.0.0.1:5610/>
- 管理：<http://127.0.0.1:5610/admin?tab=studio>
- 数字人：<http://127.0.0.1:5610/digital-human>
- F8 显示/隐藏录制控制台，或打开 `/?director=1`。

服务仅绑定本机，整个文件夹可以独立复制使用。

## 演示脚本

F8 → “播放完整流程”。脚本操作原来的按钮和表单：

1. 新建智能体 → AI 草稿 → 身份、能力、运行、确认 → 保存。
2. 提交验证 → ACS 概览 → 同步审核 → 证书占位。
3. 全网发现 → 固定执行智能体 → 首次访问刚注册的助手。
4. 科研、新闻、出行任务 → 子智能体进度、工具参数、调用链和回传。
5. 竞标任务板 → 认领者、交付证据、验收条件和复核。
6. 可选结构化输出；两轮画布写作、版本审查和接受改动。
7. 用户主持、智能体主持两种群聊 → 专家接力、共享黑板；数字人咨询入口。

主片后台只展示注册、证书及审核状态回写，不巡视其它管理页面。互联探针、设置、开放 API、运行记录等仍能手动查看，但不进入提交主片。

控制台默认隐藏，不占正式界面布局。Esc 停止脚本，不删除数据。重拍前点“重置演示”，只重置本标签页的预置状态和 `account_demo_owner` 缓存，不影响正式站。录制状态使用标签页独立的 sessionStorage，避免多个预览页互相覆盖；关闭标签页后重新恢复初始预设。单章和手动操作均可用。

自由输入按科研/新闻/出行关键词匹配预置答复，不调用模型。上传仅在浏览器中返回预置材料，不发送文件。HTTPS AIP/MQ 选择的是回执样例，不建立实际连接。

手动预览仍可使用 F8 控制台；正式录制请用 `/admin?tab=studio&record=1&theme=dark`。录制模式不创建可见控制台，F8 无效，报错也不会弹出控制面板。F9 开始或继续下一章，每章结束暂停。请用新标签页开始全流程，避免混入试录状态。

每章首先显示模块页：仅保留左上品牌标识与居中模块名，不显示编号、总数或装饰线，保持至少约 6 秒。口播分为过场引入句和操作讲解。编码仅剪除章节间等待及模块页之前的加载闪屏，不重绘或伪造正式界面帧。

## 视频

`视频/` 保存实际浏览器操作录制的 MP4、章节字幕和录制信息。按用户要求，成片不添加水印、环境标签或悬浮控制台；仅新增章节过场页。当前未合成人声，配套口播稿及可选口播 SRT 可用于本人配音。

当前主片为 `视频/AegisMesh-互联全流程-精简版.mp4`：1920×1080、H.264、24fps，289.167 秒（约 4 分 49 秒）、9,831,784 字节；符合 MP4、3–5 分钟、300MB 以内要求。12 章均从干净标签页重新录制；具体分段时间见录制信息 JSON。旧版保存在 `视频/历史版本/`，不作为当前主片。

普通聊天已移除“本次使用结构化输入输出”整块控件；能力配置和结果展示仍保留，不自动改变正常聊天请求。结构化章节展示一份预置的 API 结果会话，由 `structured-example.mjs` 使用本地接口契约初始化并幂等保存，不偷偷给聊天请求添加开关。

`口播稿.md` 是带时间码的逐段讲稿。每段先读引入句，再随操作画面讲解，不用把整段内容挤在模块页内读完。`视频/精简版检查/` 保存原生采集帧的完整性核验、无编号/无额外控件检查和每 2 秒抽样的检查缩略图。

云端真实访问数据与预置视频严格分开。按用户澄清，`访问数据截图/` 的来源是我们自己的生产服务 `https://demmo.cc.cd`，不是梧桐排行榜。已保存运行概览、调用日志、单条真实调用详情及采集状态四张原生 PNG，均无重绘；来源、时间与 SHA-256 见该目录的 `云端截图元数据.json`。截图包含真实采集告警，不用预置记录或历史数值填补。此前误查的梧桐故障截图已移入本地 `var/demo-recording-20261021/misread-platform/` 归档，不属于提交材料。

录制信息明确标记预置数据来源。视频不作为真实注册、调用、检索、证书签发、性能或合规认证的证据。新闻、论文材料和行程都是预置示例。

## 隔离

静态服务没有后端、代理或真实 `/api`。接口在浏览器本地返回 `Response`/`ReadableStream`，未知接口明确失败，绝不回退到生产。CSP 使用 `connect-src 'none'`；另行阻止原生 XHR、WebSocket、EventSource、PeerConnection、beacon 与外部跳转。字体、图片和动作视频都在本地。

身份含 DEMO、服务地址使用 `.invalid`、账号为 `example.invalid`、证书为占位路径；没有生产数据库、历史会话、密钥或私钥。导出带 `demo: true`。

## 维护与检查

- `dist/demo/fixtures.mjs`：预设智能体、问题和答复。
- `dist/demo/runtime.mjs`：接口契约、流式事件、本地历史和状态。
- `dist/demo/director.mjs`：原版 UI 录制脚本。
- `dist/demo/production-manifest.json`：正式资源哈希。
- `scripts/package-production.py /path/to/frontend/dist --source-commit <完整源码提交 SHA> --download-fonts`：更新共享前端资源，不直接修改 `dist/assets`。
- `scripts/encode-recording.py /path/to/capture ./视频`：编码实际浏览器帧。
- `scripts/audit-recording.py /path/to/capture ./视频/精简版检查`：用 Pillow 检查每张原生图片尺寸、控件隔离、深色主题、至少约 6 秒过场，生成检查报告。
- `scripts/encode-recording.py /path/to/capture ./视频 --name AegisMesh-互联全流程-精简版 --submission --audit ./视频/精简版检查/采集核验.json`：检查 12 章和时长大小上限，输出 MP4、章节字幕、口播稿与口播字幕。
- `scripts/audit-encoded.py ./视频/AegisMesh-互联全流程-精简版.mp4 ./视频/AegisMesh-互联全流程-精简版-录制信息.json`：对实际成片解码，检查 12 张模块页及口播时间码偏差。本次全片解码通过，过场约 6–7 秒，章节起点偏差最大约 0.063 秒。
